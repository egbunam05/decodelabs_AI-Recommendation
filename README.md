# Project 3: AI Recommendation Logic (Digital Matchmaker)

A content-based filtering engine built for the DecodeLabs AI program.

## 🧠 Core Concepts
* **TF-IDF (Term Frequency-Inverse Document Frequency):** Converts text skills into weighted mathematical vectors.
* **Cosine Similarity:** Measures the angle between the user's profile vector and the job role vectors, ensuring that the size of the list doesn't skew the results.

## 🚀 How to Run
1. Ensure you have Python installed.
2. Install requirements: `pip install pandas scikit-learn`
3. Run the script: `python matchmaker.py`
